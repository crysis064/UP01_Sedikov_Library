\# Система управления библиотечным фондом



\*\*Студент:\*\* \[Седиков Артём]

\*\*Группа:\*\* \[4ИСИП-323]

\*\*Тема:\*\* Учебная практика УП.01.01



\## Описание

WPF-приложение для автоматизации учета книг в библиотеке. 

Реализован полный CRUD-функционал, разграничение ролей (Администратор, Пользователь), хэширование паролей (SHA1), капча, экспорт в Word/Excel, построение диаграмм и смена тем оформления.



\## Структура решения

\* `/Pages` — WPF-страницы приложения (Авторизация, Регистрация, Таблицы и т.д.).

\* `/db/schema.sql` — скрипт создания базы данных и заполнения тестовыми данными.

\* `/res` — ресурсы приложения (иконки, изображения).
